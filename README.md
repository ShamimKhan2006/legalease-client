# 📖 Overview



LegalEase is a modern legal service platform designed to simplify the process of finding lawyers and booking appointments online. The platform provides a seamless experience for clients while offering a scalable architecture suitable for real-world legal service applications.



The project focuses on clean UI/UX, responsive design, secure authentication, optimized performance, and maintainable code architecture.

# ⚙️ Installation



Clone the repository



```bash

git clone https://github.com/ShamimKhan2006/legalease-client.git

```



Move to the project



```bash

cd legalease-client

```



Install packages



```bash

npm install

```



Run development server



```bash

npm run dev

```



Open



```

http://localhost:3000

```



---



# 🔑 Environment Variables



Create a `.env.local`



```env

NEXT_PUBLIC_API_URL=



NEXT_PUBLIC_BASE_URL=



BETTER_AUTH_SECRET=



BETTER_AUTH_URL=
```
